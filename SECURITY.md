# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| ^10.1.0   | :white_check_mark: |
| >=12.0.0   | :white_check_mark: |

## Reporting a Vulnerability

Make a ticket with the details and a thurough explination on how it can be seen, understood, what the impact of the vulnerabiliuty and if you have a suggestion, that suggestion.

You may also direct message me AFTER creating a ticket.

If a vulnerability is accepted you can expect to be credited in reports and media. 

If you help in report generation, information collection, or describing the issue, you can expect credit in media.

If you don't want to be credited, please say so so we can exclude you from any public reports.

Updates will be provided publicly on your ticket and if other tickets are created, they should refrence your original ticket.
