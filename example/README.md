# JavaScript examples

The examples in this directory run with Node.js 22.13 or newer. The `node-ipc`
JavaScript package is **Node.js-only** and uses native process, socket,
filesystem, OS, and `Buffer` APIs. It does not run in web browsers, whether
bundled or unbundled, and this directory contains no browser entry or import-map
example.

Choose the smallest transport-specific example, run each process from a
terminal, and keep network listeners on loopback unless remote access is
intentional.
