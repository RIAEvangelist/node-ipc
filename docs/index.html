Local + remote inter-process communication

Move messages between any processes.

node-ipc is a Node.js library, but its wire protocol is language-agnostic. A process written in any language can participate by following the selected transport and configured encoding and framing—plus the event envelope when framed events are used.

This site follows main and the upcoming major: one native ES module for Unix sockets, Windows named pipes, TCP, TLS, and UDP—with each concern on its own page.
