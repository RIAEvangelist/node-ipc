What counts—and what does not

90 categorized correctness cases

Only the named unit, functional, integration, and regression inventory contributes to 90. The 20 integration cases use live in-process socket pairs; they are not labelled cross-process.

Separate release gates

Cross-process fixtures, module loaders, installed-package behavior, benchmark accounting, and tracked-record validation remain visible but never inflate correctness.
