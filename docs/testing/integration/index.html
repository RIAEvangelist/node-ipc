Integration set rules

  • Every live endpoint has a deadline and deterministic teardown.
  • Every port and local endpoint is unique to the group.
  • TCP and local groups prove public peer state plus request, unicast, and broadcast flow.
  • UDP4 proves sender metadata and framed datagrams; the current inventory does not claim UDP6.
  • TLS proves an encrypted channel and cipher negotiation; it does not claim CA rejection, hostname validation, or mutual TLS cases.
