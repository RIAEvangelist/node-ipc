Defaults core configuration

  2. uses a non-empty host identity
  3. defines the local protocol namespace and delimiter

  2. sets stable network port and connection limits
  3. starts every optional client interface field disabled
  4. keeps broad local-socket permissions disabled
  5. provides an enabled console logger with bounded inspection

EventParser formatting

  1. serializes an object payload and appends one delimiter
  2. preserves a boolean false payload
  3. preserves a numeric zero payload
  4. normalizes omitted payload data to an object
  5. does not serialize event-emitter internals

EventParser frame splitting

  1. extracts one complete frame
  2. extracts multiple frames in wire order
  3. ignores an incomplete trailing frame
  4. supports a configured multi-character delimiter
  5. returns an empty list when no frame is complete
5

Public module surface

  1. exports one singleton IPC module
  2. exposes the IPC class through module instances
  3. isolates config and connection registries per instance
  4. publishes all five connection and service methods
  5. starts without a server or peer connections
5

Transport object construction

  1. client retains its configuration and logger
  2. client initializes its retry allowance from configuration
  3. client exposes its constructor and transport operations
  4. server retains path, port, and configuration
  5. server starts with neutral transport state

Unit set rules

  • One named behavior per case; no multi-purpose “works” test.
  • No network timing when a pure object or isolated state transition can prove the contract.
  • All timers, event handlers, sockets, and temporary resources must be cleaned up by the case.
  • Main-branch behavior is not considered achieved until the generated result names and passes the case.
