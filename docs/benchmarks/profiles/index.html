How to read an accepted result

Central speed

Median milliseconds per million completed messages across retained samples, paired to the baseline from the same round.

Latency distribution

One-message-in-flight p50, p95, and p99 values from the separate latency pass.

Wire accounting

Actual sent, reflected, and received byte totals plus exact message sequence and payload verification.

Always filter by OS, architecture, Node version, transport lane, payload, commit, and oracle before comparing values. Open the raw run records for those fields.
