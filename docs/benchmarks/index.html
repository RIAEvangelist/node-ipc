Measurement contract

Speed pass

Boundary timing and CPU counters only. Reports milliseconds per million messages against a paired baseline.

Resource pass

Adds memory sampling, GC observation, and event-loop delay. It is never presented as an uninstrumented speed result.

Latency pass

Keeps one message in flight and retains distribution evidence such as p50, p95, and p99.

Raw samples stay raw.

Every sample is retained. Cleanup requires natural exits, no open sockets, an immediately reusable endpoint, exact accounting, and no temporary leftovers.

Publication gates
